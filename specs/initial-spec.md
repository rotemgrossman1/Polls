## Target Users
- User
- Guest

## Product Rules
- Every poll is single choice: a participant votes for exactly one option.
- The same nickname cannot vote twice in the same poll.
- A participant sees vote counts and results only after voting, never before.
- Polls stay open; there is no closing a poll.
- There is no registration or login. The app acts as one fixed test user, who creates polls.
- Anyone who opens an invite link, including the poll's creator, takes part as a guest.

## Use Cases (Per User)

### Guest
No account and no login required.
- Accepts an invite to a poll (given a URL)
- Enters a nickname
- Views the poll question and votes for one option
- After voting, views the results: vote count and percentage for each option, and the total number of votes

### User
The one fixed test user. No registration or login in the MVP.

Has all Guest use cases plus:
- Can create a poll
- Can send link to guests to participate in the poll
