1 · Register & log in

Pattern B: separate Log in and Register screens with a colorful hero on top and a text link to switch. A failed login shows one form-level Alert, so it never reveals whether the username or the password was wrong. Register reuses the same layout.

2 · Create poll

Pattern B: the question sits in a big tinted card with large type. Options are numbered cards, and the add button is a dashed pill. More playful, but it takes more vertical space than A.

3 · Share the invite link

Pattern B: a ShareInviteModal. It is a bottom sheet on mobile (thumb-reachable) and a centered dialog on desktop. Copy confirmation happens inline, on the button itself (no toast).

4 · Accept invite + enter nickname (guest)

Pattern B: a personal invitation. The creator's avatar and a speech-bubble card hold the question, and the nickname field looks like a name tag. Invalid link = a big illustrated EmptyState.

5 · Pick an answer

Pattern B: big letter tiles (A/B/C/D). The selected tile fills with orange and its letter turns into a check mark (a shape cue, not color alone). Still a real radio group underneath, so it works with arrow keys. Try it.

6 · Results

Pattern B: a “leading” summary card first (answers “who's winning?” at a glance), then thick bars in poll order. Leader = dark bar + trophy tag. The guest's own choice = outlined “Your vote” tag with a check. On a tie, the summary card lists every tied option.
