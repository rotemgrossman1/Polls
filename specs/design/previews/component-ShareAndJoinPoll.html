Share and join poll: components

Direction: Option B, Playful. Spec: specs/features/2026-09-15-share-and-join-poll.md. Frames are 360px mobile unless marked desktop. All UI copy is from the spec's UI Copy table. Question, details, nicknames and link are sample data.

1 · Confirmation screen (changes only)

"Share poll" becomes the one primary, in the bottom bar near the thumb. "Create another poll" stays in the bar as secondary. "Back to home" moves into the content as a ghost button, so the bar keeps at most two actions (PageLayout rule). Loading and load error are unchanged from Create poll: no "Share poll".

2 · ShareInviteModal (share sheet)

Built on the shared Sheet (same as ConfirmDialog): bottom sheet on mobile, centered dialog from md. The link box shows the full link and wraps. "Copy" is the one primary and always present. After copying it turns success-filled with a check and reads "Copied" for 2 seconds; a hidden live region says "Link copied". "Share link" (secondary) shows only when the device supports sharing. "Done" is ghost, at the bottom near the thumb. Initial focus: "Copy".

3 · Invite page

NavBar minimal (logo only), so everyone sees the same page. "You're invited" is a tilted StickerHeading (the page h1). The poll sits in a PollSummary invite variant: status, option count, question, details, no options, with a speech-bubble tail pointing up at the sticker. No creator name or avatar. NicknameField uses the emphasis card. "Join poll" is the primary in the bottom bar; the whole page is one form, so Enter submits.

4 · Nickname errors and join failure

Field errors follow TextInput: icon + bold danger text + danger border and tint, focus moves to the field. Join failure is one Alert directly above the bottom bar; nickname kept, form usable.

5 · Joined screen

SuccessMark + "You're in, {nickname}" as the h1. The nickname is isolated for right-to-left text and wraps in full. Same PollSummary invite variant, bubble tail pointing at the heading. No action button and no bottom bar in this feature.

6 · Link doesn't work, load failed

Link doesn't work: EmptyState with a tilted broken-link icon in a dashed circle, heading and body, nothing else. Identical for every wrong link. Load failed: Alert with title + body, then "Try again" as the primary. Both apply to the invite page and the joined screen.

7 · Desktop (md and up)

Same single column, capped at --container-max. The share sheet becomes a centered dialog; actions stay stacked (the dialog is narrow and has three). This device has no share support, so "Share link" is hidden. The invite page's bottom bar is no longer sticky; "Join poll" sits right-aligned.
